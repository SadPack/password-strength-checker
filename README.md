# Password Strength Checker
https://sadpack.github.io/password-strength-checker/

## Project Overview
Password Strength Checker is a simple cybersecurity web project developed using HTML, CSS, and JavaScript. The purpose of this project is to check the strength of a password based on common password security rules.

## Features
- Checks minimum password length
- Recommends 12 or more characters
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Detects spaces
- Detects repeated characters such as aaa or 111
- Detects simple sequences such as 123, abc, qwerty, and password
- Displays password strength as Weak, Medium, Strong, or Very Strong
- Includes Show/Hide password option
- Responsive and visually appealing user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run the Project
1. Download or clone the project.
2. Open the `index.html` file in a web browser.
3. Enter a password in the input field.
4. The system will display password strength and rule status.
