Password Strength Checker

This cybersecurity project checks password strength and gives suggestions to improve password security.

Strength: Not Checked

Password Rules

  • At least 8 characters
  • 12 or more characters recommended
  • Contains uppercase letter
  • Contains lowercase letter
  • Contains number
  • Contains special character
  • No spaces
  • No repeated characters like aaa or 111
  • No simple sequences like 123 or abc
